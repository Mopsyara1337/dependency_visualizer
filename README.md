# Dependency Visualizer

Инструмент визуализации графа зависимостей пакетов Ubuntu (apt).

## Описание

Программа предназначена для получения информации
о зависимостях пакетов, построения графа зависимостей
и его визуализации.

## Запуск

Для запуска программы в Windows:

`run.bat`

## Конфигурация

Настройки программы находятся в файле `config.toml`.
